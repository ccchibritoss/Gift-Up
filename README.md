# GiftUp

Telegram Mini App with a blue, premium case-battle-inspired interface built from scratch for Telegram collectible gifts.

## Included
- Telegram Web App profile data when opened inside Telegram.
- Real collectible-gift artwork loaded from Fragment's NFT image endpoints.
- Case Battle with animated multi-round opening and score tracking.
- Coinflip, Mines, Upgrade, Contracts and Duels as playable virtual-score modes.
- WebRTC room prototype through PeerJS for direct player-to-player sessions.
- Local profile, inventory, statistics and match history.
- Responsive mobile-first interface suitable for Telegram Mini Apps.

## Important
This version uses virtual game points only. It does not process deposits, withdrawals, cash prizes or real-money wagering.

Telegram documents collectible gifts as transferable collectibles with unique models, backdrops, symbols and numbers: https://telegram.org/blog/collectible-gifts-and-more

The gift artwork URLs use public NFT media endpoints on nft.fragment.com. Availability of third-party media endpoints can change independently of this repository.
